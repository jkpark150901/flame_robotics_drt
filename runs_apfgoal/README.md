# 경로 계획 벤치마크: APF 영공간 경사하강 목표 자세 (2026-10-30)

폴더 이름: `{알고리즘}_{최적화}_{시나리오}`. 각 폴더는 SimTool **Load Result...** 로 불러와 재생할 수 있고(`scene_snapshot.pkl`,
목표별 `NN_<robot>_<pose>/joint_states.csv`), 평가 결과는 `eval/` (`summary.md`, `targets.csv`, `summary.json`, `METRICS.md`).
`summary.csv` = 폴더별 지표 한 줄씩 (`python python/runs_summary.py --runs-dir runs_apfgoal --out runs_apfgoal/summary.csv`),
`METRICS.md` = 지표 정의. 원본: `debug/bench_20261030_apfgoal/`.

## 조건

- 시나리오: p1 = `sample/planning_snapshot_p1_2.pkl` (목표 12), p2 = `..._p2_3.pkl` (18), p3 = `..._p3_6.pkl` (36)
- 목표 자세: 스냅샷에 미리 저장한 IK 해 (`precompute_ik_goals.py`) 를 그대로 사용 - 충돌 없는 IK (시작 자세와 가까운 해) 후
  APF 영공간 경사하강으로 센서 자세는 유지하고 나머지 링크를 장애물에서 멀리. 계획 중에는 IK를 다시 풀지 않음
  (저장된 해가 목표 자세에서 5 mm / 0.02 rad 넘게 벗어나면 실패 처리: p2 Point 2·3 pose 2 DDA, 위치 오차 9~10 mm).
- phase 2 (포지셔너 회전 후): 배관과 포지셔너 모두 회전된 장면 (이전 `runs/` 는 포지셔너가 회전 전 각도로 남아 있었음)
- OMPL, 목표당 300 s, step 0.1, 상태검사 상한 16000, 시작 = 스냅샷 자세, 회전 전 팔 접기 (트랙 유지)
- 최적화: none / chomp / stomp / gpmp2 / trajopt (APF 장애물 비용), 중간 경로만 최적화 - 시작·목표 자세가 바뀐 결과는 버림
- 평가: 몬테카를로 제외, 속도 프로파일 회전 50 °/s, 30 °/s² / 직동 0.5 m/s, 0.3 m/s²

## 핵심 결과

- 안전 실패의 대부분(계획된 DDA 경로 369건 중 322건)은 DDA 검사 방향 오차 E_θ > 5° - 목표 자세/센서 축 정의 문제로 경로와 무관.
  그래서 "안전 성공률"은 어떤 조합이든 40~60%에 머문다. 경로 자체의 안전성은 아래 "경로 안전" 표로 비교.
- 경로 안전 (C_eff ≥ 0 & 필수 비관통): 최적화 없음 90.4% → CHOMP 97.0%, STOMP 96.9%, GPMP2 98.1%, TrajOpt 95.6%.
- CHOMP 는 9개 실행 모두 여유거리 최소가 양수 (최소 4.7 mm) - 안전 마진 침범이 없는 유일한 최적화. 계획 시간 +13 s 정도.
- GPMP2 는 궤적이 가장 짧고 모션 시간도 가장 짧지만 계획 시간이 가장 길다 (목표당 100~250 s).
- RRTConnect 는 모든 시나리오에서 계획 성공률이 가장 높고 (p3 36/36) 빠르다. RRTstar 계열은 같은 조건에서도 실행마다
  계획 성공 수가 흔들린다 (플래너 무작위성) - 최적화끼리 비교할 때 감안.
