# 캐리지 바깥쪽 초기조건 IK 재계측

현재 URDF FK 확인 결과 두 로봇 모두 carriage=0m가 바깥쪽, 0.7m가 안쪽이다. 로봇 link0의 셀 좌표 y는 DDA 1.314→0.614m, RT -1.319→-0.619m로 변한다.

이전 계측도 모든 시작 관절이 0이므로 이미 같은 초기조건이었다. 이번에는 snapshot 양쪽 캐리지 상태를 명시적으로 0으로 지정하고 실제 모델 상태를 읽어 assert로 확인했다. 상대 로봇도 바깥쪽 상태이며, 각 목표는 독립 실행했다. 보정 및 시드 탐색 설정은 변경하지 않았다.

|로봇 / 목표 인덱스|이전 전체 IK(초)|재시험 전체 IK(초)|첫 IK(초)|보정+재탐색(초)|결과|
|---|---:|---:|---:|---:|---|
|rb20_1900es / 0|11.63|11.82|1.839|7.50|성공|
|dda_rb10_1300e / 0|44.28|45.01|1.222|41.69|비충돌 해 없음|
|rb20_1900es / 3|42.32|42.89|0.012|41.85|비충돌 해 없음|
|dda_rb10_1300e / 3|9.28|9.02|0.010|5.94|성공|

결론: 시작조건이 동일하여 성공/실패가 모두 동일하고 의미 있는 속도 개선은 없었다. 시간 차이는 단일 재실행 변동 수준이며 반복 통계는 아니다.

초기 캐리지 값은 고정 제약이 아니다. 현재 첫 IK에서도 캐리지는 자유변수이고, 후속 다중 시드와 근처 해 탐색은 carriage를 0~0.7m에서 무작위 추출한다. 따라서 바깥쪽 초기화가 아니라 바깥쪽 고정/축소 탐색을 의도한다면 별도 변경 및 도달률 비교가 필요하다.
