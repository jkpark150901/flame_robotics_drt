# RT 우선 접근 및 RT–DDA 충돌 검사

- 검사점별 계획 작업 생성 순서를 RT → DDA로 변경했다. 공통 inspection_group_pose_items를 사용하는 Viewer/SimTool 모두 적용된다.
- 저장 경로의 dictionary 순서와 무관하게 재생은 RT → DDA 순차 실행한다. 복귀도 같은 순서이며 두 로봇의 복귀가 끝난 후 포지셔너를 회전한다.
- PyBullet 충돌 장면마다 상대 로봇의 실제 URDF를 독립 복제한다. 상대 로봇의 현재 q 및 base transform을 검사 로봇 좌표계로 변환한다. 루트 inertial offset도 반영한다.
- 계획/검증/재생에서 사용하던 check/collides에 상대 로봇 링크 충돌을 추가했다. 계획 시에는 이전 로봇의 도착 상태, 재생 시에는 상대 로봇의 실제 현재 상태를 사용한다. 복귀 일괄 계획은 앞서 계획한 로봇의 복귀 endpoint를 뒤 로봇의 검사에 반영한다.
- 재생 시 접근은 순차 실행으로 고정한다. 두 로봇의 동시 궤적을 시간축으로 함께 탐색하는 multi-agent planner는 아니다.

## 자세 표시

회전 후 채택 자세 표시가 검증 시각화 옵션에 종속되어 있었고, 회전 검증이 지속 표시용 EF actors를 지운 뒤 임시 goal actors로 대체했다. 임시 goal 표시가 정리될 때 채택 자세도 사라질 수 있었다.

회전 후 검증 옵션과 무관하게 현재 target_groups에서 EF actors를 재생성하며, 회전 검증 완료 시와 시뮬레이션 시작 시에도 채택 자세 표시를 복원한다. 목표 자세 데이터는 유지한다.

## 검증

- 관련 테스트 20개 통과: RT 우선 작업/재생 순서, 복귀 큐가 남아 있으면 회전 지연, URDF 루트 offset/상대 base 회전/관절 이동에 따른 로봇 간 충돌 검출, 기존 경로 복구/실행 차단.
- 기존 저장 장면에서 상대 로봇을 스냅샷 자세에 둔 DDA 경로/RT 복귀 재검사 모두 우회 1회 후 성공. 독립 검사 간격 0.0025에서 충돌 edge 0개.
- `debug/latest_failure_review/peer_audit.json`, `peer_audit.log`.
- 새 순서로 전체 GUI 시퀀스 재생 및 2단계 표시의 육안 검증은 아직 수행하지 않았다. 이전 계획 결과보다는 새 순서로 재계획하는 것이 적절하다.
