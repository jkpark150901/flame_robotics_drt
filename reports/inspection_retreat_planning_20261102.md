# 포지셔너 회전 전 복귀 경로 계획

- 복귀 목표: 기존과 동일하게 linear track은 유지하고 나머지 관절을 0으로 복귀한다. `reset_pose_before_rotation` 설정을 따른다.
- 현재 회전각의 배관/포지셔너 충돌 장면으로 RRT Connect를 수행한다. linear track은 탐색 중에도 고정한다. IK와 경로 최적화는 사용하지 않는다.
- 모든 로봇의 복귀 계획이 성공한 뒤 계획 단계의 자세를 변경하고 다음 회전 단계로 넘어간다. 실패하면 회전하지 않고 준비 실패를 반환한다.
- 복귀 경로는 SimTool 결과 목록 및 재생 시퀀스에 별도 `Positioner retreat` 그룹으로 포함된다. 저장 결과에도 포함된다.
- 과거 저장 결과처럼 복귀 경로가 없는 경우에는 재생 직전에 복귀를 계획한다. 복귀 계획 또는 재생 시작 실패 시 시퀀스를 중단한다.
- 충돌 샘플 간격은 탐색/검증 시 0.02이며 실제 backend handle에도 적용하고 종료 후 복원한다. 기존 일반 검사 경로의 최종 검증에도 같은 수정이 적용된다.

## 검증

20261102_214401_RRTConnect의 RT 회전 전 복귀 구간(21번 목표 종료 자세)을 재계획했다.

- 기존 직선 복귀: 201개 샘플 중 2개 충돌.
- 수정된 RRT Connect 복귀: 9개 웨이포인트, 계획 및 검증 1.193초(장면 설정 시간 제외).
- 독립 재검사: 간격 0.005, 충돌 edge 0개.
- 결과: `debug/latest_failure_review/retreat_plan.json`.
- 관련 테스트 10개 통과: 목표 미도달/빈 경로/충돌 경로 거부, 샘플 간격 복원, 실패 시 회전 중단, 복귀 시퀀스 저장, 자세 충돌 일관성.
- 전체 기존 sequencer 테스트에서는 이번 변경 분기와 무관한 기존 기대값 불일치 3개가 남아 있다(phase-prepare fake API 부재, 확장된 playback 결과 필드, 첫 실패 후 계속 진행하는 현행 동작). GUI 전체 재생은 수행하지 않았다.

이번 변경은 로봇의 복귀 이동을 대상으로 한다. 포지셔너 회전 자체의 연속 swept collision 검사를 추가한 것은 아니다.
