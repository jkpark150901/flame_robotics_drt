# SAC 리워드와 Actor / Critic Loss 정리

기준일: 2026-11-02  
대상 실험: `goal_reward_20261102/goal1000_collision7500`

## 1. 현재 학습 구조

현재 정책은 RRT 계열 기준 경로의 중간 waypoint를 일괄 최적화하는 방식이 아니다. 기준 경로 추종 명령에 SAC가 보정 명령을 더하고, 매 step 새로운 관절 자세를 생성하는 residual 제어 방식이다.

```text
실제 명령 a = clip(기준 추종 명령 + 0.5 × 정책 출력, -1, 1)
다음 관절 자세 = 관절 범위 내로 clip(현재 자세 + a × 관절별 step 크기)
```

목표 자세는 기준으로 유지되지만 생성 경로의 도달은 보장되지 않는다. 충돌 시 종료하며, 목표 근처에서 마지막 연결 선분까지 충돌 검사를 통과하면 성공한다.

## 2. 환경 리워드

매 step 리워드는 아래 항목의 합이다. SAC 엔트로피 항은 환경 리워드와 별개이며 아래 합에 포함되지 않는다.

| 항목 | 현재 계수 | 계산 및 적용 조건 |
|---|---:|---|
| progress | 0 | `계수 × (이전 목표 거리 − 현재 목표 거리)`. 현재 비활성 |
| apf | 10 | `−10 × min(보정된 APF 비용, 5)`. step당 −50~0 |
| margin | 200 | `−200 × max(0, 0.005 − 최소 링크 거리[m])` |
| side | 0 | 팔이 파이프 반대편으로 넘어간 거리의 페널티. 현재 비활성 |
| time | 1 | 모든 step에서 −1 |
| smooth | 0.05 | `−0.05 × Σ(실제 명령 − 이전 실제 명령)²` |
| residual | 0.05 | `−0.05 × Σ(정책 출력)²`. 기준 경로 보정 크기 억제 |
| collision | 7,500 | 이동 구간 충돌 시 −7,500 후 종료 |
| goal | 1,000 | 목표 도달 조건 충족 시 +1,000 후 종료 |

충돌 step에서는 progress/APF/margin/side/goal 계산을 건너뛰고 collision을 적용한다. time/smooth/residual은 충돌·성공 step에도 적용하므로 성공 step의 총 리워드가 정확히 +1,000인 것은 아니다. 500 step 시간 초과에는 별도의 종료 페널티가 없다.

### APF 거리 비용과 보정

영향 거리 `d0 = 0.3 m`, 링크별 장애물 거리 `d_i`에 대해:

```text
d_i = max(d_i, 0.001 m)
U = Σ [0.5 × (1/d_i − 1/d0)²]     (d_i < d0인 링크만 합산)
w_start = max(0, 1 − 시작 자세까지 관절 거리 / 0.15)
w_goal  = max(0, 1 − 목표 자세까지 관절 거리 / 0.15)
U_corrected = max(0, U − max(U_start × w_start, U_goal × w_goal))
r_apf = −10 × min(U_corrected, 5)
```

시작·목표 자세의 불가피한 근접 비용을 일부 빼준다. 여기서 관절 거리는 관절 가동 범위로 정규화하고 관절 가중치를 적용한 L2 거리다. `sigma=0.15`는 미터가 아니다. 보정은 EE 거리나 궤적 마지막 구간 판정이 아니므로 중간에 목표 관절 자세 근처를 지나가도 적용된다.

### 도달 판정

목표까지 정규화 관절 거리가 `reach_tol=0.05` 미만이고, 현재 자세에서 정확한 목표 자세까지의 연결 선분이 충돌하지 않아야 한다. 성공 시 경로에 정확한 목표 자세를 추가한다. EE 위치 오차 5cm 기준이라는 뜻은 아니다.

### 리워드 규모 해석

- APF 페널티 상한은 기존 −2,000에서 −50으로 축소했다.
- margin 계수가 200이어도 거리를 m로 곱하므로 거리 0mm에서 −1이다. 계수 숫자만으로 항목의 영향력을 비교할 수 없다.
- 도착 보상은 성공을 유도하지만 경로 안전성이나 도달을 보장하지 않는다.
- 리워드 정의를 바꾸면 총 리워드의 척도도 바뀐다. 다른 실험의 리워드 절댓값으로 모델 순위를 정하지 않는다.

## 3. Actor Loss — 정책 업데이트 목적함수

설치된 Stable-Baselines3 SAC 구현의 계산식:

```text
L_actor = mean[ α × log π(a|s) − min(Q1(s,a), Q2(s,a)) ]
a ~ 현재 정책 π
```

| 구성 | 의미 |
|---|---|
| π(a\|s) | 상태 s에서 보정 명령 a를 선택하는 정책의 확률밀도 |
| α × log π | 정책 엔트로피를 유지해 탐색을 유도하는 항 |
| min(Q1,Q2) | 두 critic 중 작은 예측값. 가치 과대평가를 줄이기 위한 구성 |
| 음의 Q 항 | 예측 누적 가치가 높은 행동을 선택하도록 유도 |

Actor는 이 loss를 최소화한다. 하지만 critic 예측과 엔트로피 계수가 동시에 변하므로 loss 하락 자체가 도달률 상승을 뜻하지 않는다. 값은 음수일 수 있고 0으로 수렴해야 하는 지표도 아니다. 다른 보상 척도의 실험끼리 actor loss 크기를 직접 비교하면 안 된다.

현재 `ent_coef=auto`이므로 α도 학습한다. 환경 리워드가 동일해도 α 변화가 actor loss에 영향을 준다.

## 4. Critic Loss — 누적 가치 예측 오차

현재 1-step SAC 구성에서 목표값과 loss는 다음과 같다.

```text
a_next ~ π(·|s_next)
y = r + γ × (1 − terminal) × [min(Q1_target, Q2_target)(s_next,a_next)
                              − α × log π(a_next|s_next)]
L_critic = 0.5 × [MSE(Q1(s,a), y) + MSE(Q2(s,a), y)]
```

| 구성 | 의미 |
|---|---|
| r | 해당 step에서 환경이 반환한 리워드 |
| γ | 할인율. 현재 0.99 |
| terminal | 실제 종료 여부. 충돌·성공은 종료, 시간 제한 truncation은 SB3 replay 처리에서 구분 |
| Q_target | 안정적인 목표값 계산을 위한 target critic |
| MSE | 예측 누적 가치와 목표값 차이의 제곱 평균 |

Critic loss는 음수가 아닌 가치 예측 오차다. 리워드가 커지면 제곱 오차의 척도도 커진다. 정책·경험 데이터·target critic이 계속 바뀌므로 학습 내내 단조 감소하지 않을 수 있다. 작은 critic loss는 예측 일관성의 신호일 수 있지만 안전한 경로를 잘 찾는다는 보장은 아니다.

Target critic은 `tau=0.005`로 점진 갱신한다. 배치 크기는 512, 학습률은 0.0003이다.

## 5. 기록 방식과 조기 종료

| 기록 | 집계 방식 |
|---|---|
| TensorBoard `train/actor_loss`, `train/critic_loss` | SAC의 한 train 호출 내 gradient update loss 평균. 현재 gradient_steps=8 |
| TensorBoard `custom/reward_*` | 최근 종료 에피소드 최대 200개의 항목별 누적 리워드 평균 |
| `convergence.jsonl`의 reward | 약 5,000 step 구간에서 종료된 에피소드들의 총 리워드 평균 |
| `convergence.jsonl`의 actor_loss / critic_loss | 구간 내 callback이 수집한 최신 SAC loss 기록의 중앙값 |
| `convergence.jsonl`의 success | 해당 구간 종료 에피소드의 도달 성공 비율 |

에피소드 리워드는 할인하지 않은 합이다. Critic은 엔트로피를 포함하는 할인 누적 가치를 학습하므로 둘은 동일한 수치가 아니다. 구간에 시작했지만 아직 끝나지 않은 에피소드는 그 구간 reward 평균에 포함되지 않는다.

2.5만 step 이후 아래 조건을 3회 연속 만족하면 plateau로 종료하도록 설정했다.

- 인접 구간 reward, actor loss, critic loss 각각의 상대 변화가 10% 이하.
- 상대 변화 분모는 `max(abs(이전값), abs(현재값), 1)`.
- 구간 성공률 차이가 5%p 이하.

이는 운영용 안정화 휴리스틱이며 수학적인 수렴 보장이 아니다. 최대 실행량은 6만 step이다. 16개 병렬 환경 때문에 창 경계가 5,008 step 간격이었고, 마지막 완전 구간은 55,088 step이다. 60,000 step 종료 시 남은 부분 구간은 `convergence.jsonl`에 별도 집계하지 않았다.

| 구간 종료 step | 평균 에피소드 리워드 | Actor loss 중앙값 | Critic loss 중앙값 |
|---:|---:|---:|---:|
| 10,016 | −5,977 | 129 | 134,333 |
| 20,032 | −7,228 | 243 | 80,684 |
| 30,048 | −7,473 | −880 | 84,367 |

| 50,080 | −5,039 | −2,702 | 115,689 |
| 55,088 | −5,238 | −2,991 | 117,488 |

6만 step, 약 28분 학습 후 `step_limit`으로 종료했다. 마지막 기록에서 안정화 조건을 한 번 만족했지만 연속 3회 조건은 충족하지 못했다. 리워드 변동과 critic loss 재상승이 있어 수렴 완료로 판단하지 않는다.

| 평가 | 목표 도달 | 경로 안전 통과 |
|---|---:|---:|
| 기본 씬 / SAC | 5/7 | 5/7 |
| 기본 씬 / SAC + Shield | 7/7 | 6/7 |
| 장애물 증강 3개 시드 / SAC | 5/21 | 5/21 |
| 장애물 증강 3개 시드 / SAC + Shield | 5/21 | 5/21 |

경로 안전 통과는 도달 성공, `C_eff >= 0`, 필수 기하 조건을 모두 만족한 경우다. side 리워드는 제거했지만 평가의 필수 기하 조건에는 기존 반대편 제약이 남아 있으므로 두 항목을 혼동하지 않는다. 최종 검사 자세 정확도까지 포함한 완전 성공 지표와도 구분한다.

모델 선택은 loss 최솟값 대신 동일 평가 목표·장애물 시드에서의 도달률, 경로 안전성, 여유거리로 판단한다. 실패 사례를 제외한 평균 여유거리만으로 순위를 정하지 않는다.
