4.1 공통 규칙

  • 관절 순서: 0 ~ 5 = J1(base) ~ J6(wrist3)
  • 각도 단위: traj_ref.csv, traj_sub10.csv 는 rad, 나머지는 deg
  • 첫 줄이 # 로 시작하는 CSV: 첫 줄은 JSON 메타데이터, 둘째 줄부터 일반 CSV

    • t_track: 모션 시작 시각 기준 [s] (모션 시작 = 시작 자세에서 0.2° 넘게 벗어나기 직전 샘플)
