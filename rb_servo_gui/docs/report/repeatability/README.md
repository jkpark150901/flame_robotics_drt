## 방향 예비 분석

10/08 servo 두 실행의 엔코더각을 원본 6관절 꺾은선의 최근접 선분에 투영하고,
`오차 = 측정각 - 투영점`의 부호를 비교했다. 경로 누적 길이 5~95%를 1% 폭 90구간으로 나눠
각 실행에서 최소 2개 측정점이 있는 구간의 평균 오차를 비교했다.
시간 오차를 제거한 관절공간 경로 잔차이므로 TCP/작업공간 오차 방향과는 다르다.
전역 최근접 투영은 자기 교차·가까운 반복 구간에서 대응이 모호할 수 있으며 시간 순서는 보장하지 않는다.

두 실행의 평균 오차 벡터 크기가 모두 0.02°를 초과한 76구간:
- 방향 코사인 중앙값 0.98494 (1에 가까울수록 같은 방향)
- 내적이 양수인 구간 72/76 = 94.7%

관절별로는 두 실행 모두 |평균 오차| >0.02°인 구간에서 부호 일치:
J1 100%(44구간), J2 98.1%(54), J3 100%(48), J4 95.3%(43), J5 100%(45), J6 100%(40).
0.02°는 미소 오차의 불안정한 부호를 제외하기 위한 분석 기준이며 센서 정확도 인증값이 아니다.
